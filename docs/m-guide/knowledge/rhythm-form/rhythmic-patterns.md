# Mẫu nhịp điệu trong sáng tác

> **AI:** Đọc ở Bước 3 khi cần catalog pattern cụ thể theo section. Bổ sung cho [groove-and-syncopation](groove-and-syncopation.md) (pulse / syncopation / lyric stress) — không thay trang đó.

## Dùng ở bước nào

- Bước 3 — chọn mẫu onset / mật độ tiết tấu cho melody + lời theo section.

## Constraints

- Không đổi `tempo` / `time_signature` đã locked chỉ để khớp một pattern gợi ý.

## Hints

| Pattern | Mô tả | Gợi ý section |
| ------- | ----- | ------------- |
| Straight | Onset đều, ít đảo phách | Verse ổn định |
| Syncopation | Nhấn phách yếu / giữa phách | Pre / chorus |
| Dotted | Dài–ngắn xen kẽ | Lướt, ballad nhẹ |
| Triplet | 3 nốt trong 1 phách | Đẩy năng lượng cục bộ |
| Rest-forward | Dùng lặng có chủ đích | Nhấn từ khóa, tạo khoảng |

Gợi ý gắn section (xu hướng, không luật):

| Đoạn | Pattern gợi ý |
| ---- | ------------- |
| Intro | Thưa, straight |
| Verse | Straight + ít syncopation nhẹ |
| Pre-chorus | Tăng syncopation / mật độ |
| Chorus | Syncopation hoặc triplet có điểm tựa |
| Bridge | Dotted hoặc nhiều rest hơn (tương phản) |
| Outro | Giảm mật độ |

Với tiếng Việt: pattern phải tôn trọng trọng âm từ và thanh điệu — xem [syllable-priority](../vietnamese/syllable-priority.md).

## Cách áp dụng

1. Chọn cảm xúc section → chọn 1 pattern chính.
2. Viết onset melody theo pattern, rồi gắn lời.
3. So sánh density giữa verse và chorus (tránh một màu).
4. Kiểm tra lyric stress không bị “vặn” quá mức.

## Ví dụ ngắn (tự viết)

- Verse: nốt đen thẳng, ít đảo.
- Pre: móc đơn + rest tạo hụt hơi trước chorus.
- Chorus: triplet cục bộ trên phách mạnh, phần còn lại có điểm tựa.
